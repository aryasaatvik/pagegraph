PageGraph is an npm library for route-declared SEO in TanStack Start and TanStack Router. Each route declares its SEO policy and head once, in `staticData.seo`. The `<head>`, sitemap, `robots.txt`, breadcrumbs, JSON-LD, cross-links and the CI check all derive from that declaration, so there are no files to keep in sync by hand.

The `pagegraph()` Vite plugin builds a graph from your routes inside your app's own Vite pipeline. The `pagegraph` CLI reads the same graph, so `pagegraph check` can fail a build when a declaration is broken. With the opt-in coverage gate, a page in an enforced route group that declares neither `staticData` nor `head` fails the build.
