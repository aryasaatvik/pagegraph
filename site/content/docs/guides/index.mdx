Each guide covers one task. If you have not set PageGraph up yet, start with the [quick start](/docs/quick-start).

- [Gate CI with pagegraph check](/docs/guides/ci-check): fail CI on structural violations and check rendered HTML.
- [Add per-page Open Graph images](/docs/guides/og-images): declare images and share one resolver.
- [Publish Markdown twins and llms.txt](/docs/guides/markdown-twins): capture rendered pages as Markdown on TanStack Start.
- [Enforce route coverage in Vite](/docs/guides/coverage-gate): fail the build when a page declares no SEO.
- [Check contextual links](/docs/guides/contextual-links): set inbound-link minimums, verify served links, propose new ones.
- [Gate claims in page copy](/docs/guides/claims-gate): replay committed answers to policy questions.
- [Run agent workflows](/docs/guides/agent-workflows): research, analyze and improve with Pi, Executor and Jev.
- [Audit any website](/docs/guides/audit): audit a URL and compare two audit reports.
- [Use PageGraph without TanStack Start](/docs/guides/without-tanstack-start): build the graph from a TanStack Router tree.
