### Run the CLI on Effect 4.0.6 and Pi 1.0.4

Breaking: Pi renamed its Azure OpenAI provider from `azure-openai-responses` to `azure`. A workflow
model such as `azure-openai-responses/gpt-4.1` in `workflows.agent.defaultModel`,
`workflows.agent.models`, or `--model` now fails with `Unknown Pi model`; write `azure/gpt-4.1`
instead. `AZURE_OPENAI_API_KEY` is unchanged.

The CLI now bundles Effect 4.0.6 and Pi 1.0.4. Committed claims answers stay valid, so
`pagegraph claims check` keeps replaying them without `--refresh`.
